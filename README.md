# Gifted Global

תבנה לי אתר למכירת מתנות, אתר לקנית מתנות לאחרים, לדוג סבא שגר בצרפת שיקנה מתנת בת מצוות לנכדה שלו בארץ וכד'

אתר בעיצוב יוקרתי סטייליסטי, עם אופציה לשנות את שפת האתר, שיהיה 3 שפות, עברית צרפתית ואנגלית

יהיה תפריט עליון: בית (שם יוצג הפרסומת שתכנע לקנות עם תמונות של מתנות רלווונטיות, ועוד כל מיני דברים מענינים)

חגים (עם תת תפריט של ראש השנה, סוכות, חנוכה, טו בשבט, פורים, פסח,שבועות)

שבת

 יומולדת (עם תת קטגוריה של ילד\ה, נער\ה, מבוגר\ת) 

לתינוק

בר מצווה

בת מצווה

אודות (שם יהיה תיאור כלשהו על האתר והחזון או משהו בסגנון)

סל קניות

כל לחיצה על קטגוריה מסויימת תציג את כל המנות שבקטגוריה (עם אופציה של הוספה לסל, יציג מחיר), לחיצה על מתנה מסוימת תפתח חלון PREVIVIEW כזה שיציג עוד תמונות של אותה מתנה + תיאור + מחיר+ כפתור של הוספה לסל

תהיה אופציה גם לקניה מיידית של המוצר,

כאשר עוברים לקניה או מהסל או מהמוצר, יצטרכו למלאות שם, ( להדגיש ללקוח שזה השם שהמקבל המתנה יראה) טלפון,  אופציה לכתיבת מכתב (עבור כל מתנה ולא עבר כל ההזמנה), כתובת למשלוח המתנה, פרטי אשראי לתשלום
